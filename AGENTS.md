# Agent guide

The guide for this repository is **[CLAUDE.md](CLAUDE.md)**, which applies to
any coding agent working here, not only Claude. It covers the commands, the
package layout, the invariants, and the conventions.

Before you start, read in this order:

1. [CLAUDE.md](CLAUDE.md) — how to build, test and run it, and the nine
   invariants that must not be broken.
2. [docs/PLAN.md](docs/PLAN.md) — what Maya is meant to become, which phases
   are done, and what the next one has to do.
3. [docs/FINDINGS.md](docs/FINDINGS.md) — the traps. Read this before touching
   an adapter, the terminal code, or a dependency version.
4. [docs/adr/](docs/adr/) — decisions that went against the original plan, and
   why.
